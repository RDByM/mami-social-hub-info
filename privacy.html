Mami Social Hub — Privacy Notice

Last updated: 18 October 2026.

Scope

Mami Social Hub is a locally operated social media management application. This notice describes the TikTok sandbox connection under development for basic account identification only. It does not describe the separate Sleepy Mixer Android application.

Information processed

With your authorization, the connection requests TikTok's user.info.basic scope. The current adapter requests your TikTok application-specific account identifier (open_id) and display name. An access token is used to authenticate requests. Your TikTok password is entered only on TikTok's own login pages, not stored by this adapter.

Purpose and storage

The identifier and display name are used to identify the account connected to the selected local workspace and to detect account mismatches. Account records are stored in the local SQLite database. Stored access tokens are encrypted using Windows DPAPI. Local database backups may also contain these records. This sandbox connection does not enable video publishing.

Disclosures

The access token is sent to TikTok's official API to verify the authorized account. This adapter does not send the token to OpenAI or other social networks. Other optional integrations have separate data flows and permissions; this notice does not authorize them. Any public website hosting this notice may process access logs under its own policy.

Retention, withdrawal and deletion

Connection records remain locally until the operator removes them; no automatic retention period is currently implemented. Access can be revoked through TikTok's connected-app controls where available. Revocation does not itself delete local records or backups. Requests to inspect or delete local records and retained backups must be directed to the operator. Deletion must be verified before it is reported complete.
